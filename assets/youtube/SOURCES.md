# YouTube Premium 헤더 로고

`premium-logo.svg`는 아래 YouTube 공식 리소스에서 정리한 로컬 헤더용 에셋입니다.

- 확인 페이지: https://www.youtube.com/premium
- 공식 브랜드 안내: https://brand.youtube/
- Premium 워드마크 원본: https://www.gstatic.com/youtube/img/promos/growth/YTP_logo_social_1200x630.png
- 재생 아이콘 원본: 공식 Premium 페이지의 `yt-ringo2-svg` 첫 번째 그룹(SVG 경로, 색상 `#FF0033`).
- 확인일: 2026-10-23

공식 PNG의 Premium 글자 부분을 추출해 흰색/투명 배경으로 변환하고, 공식 아이콘과 결합했습니다. 원본 배포 파일 그대로가 아닌 다크 헤더용 파생 에셋이며, 일반 글꼴로 재작성하지 않았습니다. 워드마크는 PNG로 SVG 안에 포함되어 외부 이미지나 폰트에 의존하지 않습니다. 외부 페이지의 스크립트는 다운로드하거나 실행하지 않았습니다.
